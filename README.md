# AARA Computers Website

Official website and assets for **AARA Computers** (Vadapalani, Chennai) — Computer Education & Practical IT Services since 2012.

## Project Structure
- `AARA-COMPUTERS-WEBSITE-main/` — Full responsive website source:
  - `index.html` — Home page with 3D ring carousel, interactive course orbits, student success metrics & ISRO Best Teaching Award showcase
  - `about.html` — About Us, organizational profile, 3D recognition & story
  - `courses.html` — Core courses, technical certifications & syllabi
  - `services.html` — Professional IT services, networking, CCTV, web development & hardware solutions
  - `gallery.html` — Interactive gallery and 3D student life showcase
  - `media.html` — Press coverage, events and media archives
  - `contact.html` — Contact details, Google Maps integration & inquiry forms
  - `assets/` — CSS styles (`styles.css`, `premium.css`), JavaScript (`main.js`, `premium.js`), icons, images, and videos
- `DEPLOY-HOSTINGER.md` — Guide for Hostinger deployment via hPanel or FTP
